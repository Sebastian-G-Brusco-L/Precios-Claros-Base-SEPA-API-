# API REST - Precios Claros SEPA

Este proyecto es una API REST basada en **Precios Claros - Base SEPA**, desarrollada con **Spring Boot**, **Spring Data JPA** y **SQLite**.

SEPA (Sistema Electrónico de Publicidad de Precios Argentinos) reúne los precios de comercios minoristas (grandes establecimientos) de más de 70 mil productos en todo el país, generando una base diaria de aproximadamente 12 millones de registros.

📌 **Sitio oficial:** [Precios Claros](https://www.preciosclaros.gob.ar/terminos_y_condiciones.html)  
📩 **Contacto:** soportesepa@comercio.gob.ar
